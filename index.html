PuertoLoquerón

A map-first trip companion for four friends in Puerto Escondido.

Share a TikTok into the app and a Supabase Edge Function reads the places it mentions. Each one is checked against Google Places, and the verified ones are pinned on the shared map. Every place keeps the post it came from and who recommended it.

Expenses split four ways with a settle-up that tells each person exactly who to pay, and a daily reminder until they do.

  • Supabase
  • Google Places
  • Maps
  • Expo
Built for one trip, September 2026. Not on the stores.
RT

Recibidor TI

An intake log for a company receiving three hundred rented laptops back from staff.

A React web console assigns work, prints receipts and exports the reconciliation. On the floor, four technicians use the mobile app to open a folio per device, match expected serials against what arrived, record missing parts, and attach photo evidence of the secure erase.

The domain lives in one shared package with a Spanish glossary mapped to a single English identifier per term, so the console and the mobile app never disagree about what a Reception is. Both run on the same Supabase backend.

  • React + Vite console
  • Supabase
  • Monorepo
  • Expo
