# Portfolio — Domain language

**Side project**:
One of the three current products shown in full on the page (VerseGuard, PuertoLoquerón, Recibidor TI). Has a case study, media, and links.
_Avoid_: highlight, featured project, main project

**Experience**:
A job shown as a postcard in the Experience section (PEMEX, then Remine). Each one is its own Stop.
_Avoid_: role, position

**Archive entry**:
An early (2021-era) project listed by name and GitHub link only, collapsed by default. No media, no case study.
_Avoid_: old project, portfolio item

**Case study**:
The short text on a Highlight: problem, what was built, stack. Three to five lines.

**World**:
The fixed Three.js ocean behind the page. Decorative, never carries content.

**Stop**:
A block of content marked with `data-stop` where the surfer holds position: hero, pemex, remine, verseguard, puertoloqueron, recibidor, earlier, contact.

**Ride**:
The scroll-driven journey of the surfer through the Stops, from dawn to dusk.

**Skill strip**:
The compact row of technology icons. No prose.
